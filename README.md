# Sankalp Gupta — Portfolio Website

A responsive personal portfolio built with **HTML, CSS, and JavaScript** to present my profile, technical skills, projects, and contact information in a clean single-page experience.

## Live Portfolio

**Live:** https://sankalp-gupta1.github.io/New-port-/

## Overview

The website is structured as a simple portfolio landing page with dedicated sections for:

- Home / introduction
- About me
- Technical skills
- Featured projects
- Contact
- Responsive mobile navigation

The project is intentionally lightweight and does not require a frontend framework or build step.

## Featured Projects

The portfolio currently highlights projects including:

- **Live Weather Forecast**
- **Smart Banking Management**
- **AI-Based Theory Generator**
- **Artificial Mouse Controller**
- **Gesture Volume Control**

Each project card links to the related GitHub repository.

## Run Locally

No installation is required.

Clone the repository:

```bash
git clone https://github.com/Sankalp-gupta1/New-port-.git
cd New-port-
```

Then open `index.html` in a browser.

For a local development server, you can also use the VS Code **Live Server** extension.

## Deployment

This repository can be deployed directly with GitHub Pages because it is a static HTML/CSS/JavaScript project.

## Notes

The contact form is currently a frontend interaction and displays a confirmation message in the browser; it is not connected to a backend mail service.
